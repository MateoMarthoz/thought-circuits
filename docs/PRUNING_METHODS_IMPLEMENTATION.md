# Implementation reference: Edge-Pruning, GSEP, SSEP, JSEP, GSNP, and GSNP_GSEP

This document describes how each method is implemented in this repository, following the actual code paths in `Edge-Pruning` and `causal_cot`. Terminology matches the source files: writers and readers for Edge-Pruning, reasoning-step indices for causal CoT methods (zero-based in GSEP and GSNP JSON, one-based step ids in JSEP and SSEP training code where the prompt occupies index zero).

**Global notation used below (formal).** Let the clean token sequence be `x = (x_0, ..., x_{L-1})` and clean logits be `f_clean(x)`. Let reasoning steps be contiguous token spans `R_t = [s_t, e_t)` with `0 <= t < N` in zero-based indexing for greedy scripts (`GSEP`, `GSNP`, `GSNP_GSEP`). For training methods (`SSEP`, `JSEP`), step id `0` denotes prompt tokens and reasoning steps are `1..N`. Step loss is always next-token cross-entropy over the prediction window: logits at positions `s..e-2` predict labels at `s+1..e-1`, so the first token in each step is never scored. Unless explicitly stated, model weights are frozen and only intervention structure changes.

## Edge-Pruning (FLlama)

Edge-Pruning is implemented as a modified Llama stack (`FLlamaModel`, `FLlamaDecoderLayer`, and attention variants under `Edge-Pruning/src/modeling/modeling_fllama.py`) plus L0 mask sampling in `Edge-Pruning/src/modeling/l0_fllama.py` and a custom trainer in `Edge-Pruning/src/prune/fllama_boolean_expressions_fs.py`. The design reframes the transformer as a graph whose nodes are computational units that **write** activations into a bank of writer slots, and whose **readers** consume weighted sums of those writers. Each allowed connection from a writer to a reader is an **edge** parameterized by a `log_alpha` value; training learns which edges to keep while matching a dense reference model.

**Formal specification.** State variables are edge-mask logits `alpha_e` over all legal writer->reader edges and node-mask logits `alpha_n` over writer nodes. At each training step, stochastic masks are sampled with Hard Concrete: `z_e ~ HC(alpha_e)`, `z_n ~ HC(alpha_n)`, both in `[0,1]`. For each reader input, hidden activations are mixed as `h_reader = sum_w z_e[w, reader] * h_w + sum_w (1 - z_e[w, reader]) * h_corr_w` when corruption cache is enabled; for each writer output, node gating is `h_w_out = z_n[w] * h_w_clean + (1 - z_n[w]) * h_w_corr`. The supervised objective is distillation on selected positions `I`: `L_KL = KL(log_softmax(f_pruned(x)_I) || log_softmax(f_teacher(x)_I))`. Sparsities are `S_edge = 1 - mean(z_e)` over legal edges and `S_node = 1 - mean(z_n)` over writer nodes. Regularizers are `L_edge = lambda_e1*(S_edge - tau_e) + lambda_e2*(S_edge - tau_e)^2` and `L_node = lambda_n1*(S_node - tau_n) + lambda_n2*(S_node - tau_n)^2` with warmup schedules for targets `tau_e, tau_n`. Total training loss is `L = L_KL + L_edge + L_node` (with optional node-term skips per config). At evaluation, masks become deterministic via `deterministic_z_from_log_alpha`, optionally thresholded to binary, and surviving graph edges are enumerated from nonzero masks.

**Writers and readers.** The helper `num_writers` counts one optional embedding writer if `with_embedding_nodes` is true, then for every transformer layer adds `num_attention_heads` attention-head writers plus one MLP writer, so each layer contributes `H+1` writers. The helper `num_readers` counts, per layer, `H` query readers, `num_key_value_heads` key readers, `num_key_value_heads` value readers, and one MLP reader, then adds a single final reader `resid_post` that aggregates into the residual stream. The helper `num_edges` counts every trainable reader–writer connectivity pattern the masks are meant to represent: if embedding nodes exist, the embedding writer connects to all readers once; for each layer, each attention head writer connects to that layer’s MLP reader plus all readers in later layers and the final read, and the MLP writer connects to all future-layer readers plus the final read, with closed-form sums over remaining depth.

**Per-layer parameters.** Each `FLlamaDecoderLayer` owns `q_read_log_alphas`, `k_read_log_alphas`, and `v_read_log_alphas` with shape `(num_writers, H or num_kv_heads)` for attention Q/K/V inputs, `mlp_read_log_alphas` of shape `(num_writers,)`, `attn_write_log_alphas` of shape `(H,)` for attention output nodes, and `mlp_write_log_alphas` scalar-expanded for the MLP output node. `attn_read_common_mask` is a broadcast column mask that is zero for writers at or after the current layer’s attention writer index and one before it, so attention readers only sum over **prior** writers (causal depth in the circuit graph). Similarly `mlp_read_common_mask` gates MLP inputs to prior writers only. `attn_write_common_mask` is a padded identity that routes each head’s post-attention vector into exactly one writer row in the writer tensor. `mlp_write_common_mask` selects the single MLP writer row.

**Mask generation.** `get_mask(log_alpha, training, threshold_for_deterministic, apply_one)` chooses between stochastic L0 **Hard Concrete** samples during training (`sample_z_from_log_alpha`: uniform `u` in `(EPS, 1-EPS)`, inverse CDF map with temperature `TEMPERATURE = 2/3`, affine stretch to `[LIMIT_LEFT, LIMIT_RIGHT] = [-0.1, 1.1]`, then `hardtanh` to `[0,1]`) and deterministic masks at evaluation (`deterministic_z_from_log_alpha`: expected zero count from CDF at zero, `sigmoid(log_alpha / TEMPERATURE * 0.8)` ranking, zero out the smallest `num_zeros` entries, optional binarization to ones). If `threshold_for_deterministic` is set, evaluation additionally thresholds the deterministic mask to binary. The model exposes `set_edge_threshold_for_deterministic` / `set_node_threshold_for_deterministic` on every layer for calibration scripts that binary-search thresholds to hit a desired sparsity.

**Forward data flow.** `FLlamaModel.write` either applies a token-embedding node mask (`with_embedding_nodes`) and places token embeddings into writer slot zero, or allocates a zero writer tensor and passes token embeddings separately as `embeds`. Each decoder layer receives `hidden_states` shaped `(num_writers, batch, seq, hidden)` plus optional `embeds` and optional `corr_x` of the same writer layout. In `attn_read`, masks `q_m,k_m,v_m` are multiplied by `attn_read_common_mask`; the gated writers are einstein-summed into per-head Q, K, and V tensors; `embeds` are added into Q/K/V; if `corr_x` is present, `(1-mask) * common_mask` weights corrupted writer activations into Q/K/V so **masked-off** edges read from the corruption path. `z_edges_sum` accumulates the sum of active edge masks for regularization accounting. After RMSNorm, standard Llama self-attention runs on those mixed Q/K/V. `attn_write` applies node masks `z` on the attention output per head, optionally blends `corr_x` for disabled nodes, scatters into the writer tensor via `attn_write_common_mask`, and accumulates `z_nodes_sum`. `mlp_read` mirrors attention read mixing with `mlp_read_common_mask`; the MLP block runs; `mlp_write` applies the MLP node mask, optional `corr_x` blend, and writes into the MLP writer row. After all layers, if `output_writer_states` is true the full writer tensor is returned as `writer_states` for the corruption cache path. `read` applies `final_read_log_alphas` to mix writers into the final hidden state, again with optional `corr_x` for edges set to zero. RMSNorm finishes the stack.

**Global sparsity and losses.** The forward sums all per-layer `z_edges_sum` contributions plus the final read, then computes `model_edge_sparsity = 1 - z_edges_sum / num_edges` and `model_node_sparsity = 1 - z_nodes_sum / num_nodes` where `num_nodes == num_writers`. When `target_edge_sparsity` and `target_node_sparsity` are provided, `edge_loss` and `node_loss` are Lagrange-style terms `lambda_1 * (model_sparsity - target) + lambda_2 * (model_sparsity - target)^2` using learnable `sparsity_lambda_edges_*` and `sparsity_lambda_nodes_*` parameters (with an option in the constructor to zero the linear term via `disable_linear_regularization_term`).

**Training loop (`FLlamaTrainer.compute_loss`).** A frozen reference `llama_model` runs the clean `input_ids` to obtain teacher logits. The same reference runs `corr_input_ids` with `output_writer_states=True`, storing `writer_states` as `corr_x`. The trainable `FLlamaForCausalLM` (the prunable model) runs on clean `input_ids` with `corr_x` injected and with scheduled targets from `get_current_edge_target_sparsity` / `get_current_node_target_sparsity` (linear or logarithmic warmup over `num_edge_sparsity_warmup_steps` and `num_node_sparsity_warmup_steps`). The objective is `KL( log_softmax(pruned logits[idx]) || log_softmax(teacher logits[idx]) )` summed over batch positions in `idxes`, averaged by batch size, **plus** `edge_loss + node_loss` where `node_loss` can be disabled or skipped when node sparsity already exceeds the target (`skip_node_loss_if_higher_sparsity`). Optimizer construction (in the same file via `get_optimizers`) uses separate learning rates for mask parameters versus regulator parameters, with regulators maximized.

**Post-training extraction.** `get_edge_masks`, `get_node_masks`, `get_edge_sparsity`, `get_effective_edge_sparsity` (edges multiplied by active node masks), and `get_edges` enumerate surviving edges as human-readable `(writer_name, reader_name)` pairs using `writer_idx_to_name` and `reader_idx_to_name`. `load_all_log_alphas` can hard-initialize masks from a list of such edges by setting matched entries to `10` and others to `-10`.

## GSEP (Greedy Step Edge Pruning, backward ablation)

GSEP is implemented in `causal_cot/run_gsep.py` as a **per-target-step** backward greedy procedure with **no weight updates**: the model stays frozen. The script loads a clean chain-of-thought, parses reasoning steps inside `<think>` via `parse_reasoning_steps`, maps each step to absolute token spans with `map_steps_to_tokens`, and verifies that those spans align with the think-inner tokenization using `assert_reasoning_token_ranges_match_think_inner`. It loads one or more perturbed texts from `perturbed_*.txt` and resampled texts from `resampled_*.txt`, enforcing identical reasoning-step counts and **byte-for-byte identical per-step token spans** between clean and each perturbation so that key–value substitution indices are shared. A single clean forward with `use_cache=True` builds `past_key_values` for the attention-suppression path.

**Formal specification.** For each target step `T in {0, ..., N-1}` and each intervention family `m in {attn_supp, resample, perturb, perturb_text}`, define candidate source set `C_0(T) = {0, ..., T-1}` and pruned set `P_0(T) = empty`. Round `r` evaluates every `i in C_r(T)` by applying intervention `m` with active source set `P_r(T) union {i}`, then computing target-step delta `Delta_m(T, i | P_r) = mean_c[ CE_mixed^{(c)}(T; P_r union {i}) - CE_clean(T) ]`, where `c` indexes corruption variants when applicable. Selection rule is greedy minimization: `i_r* = argmin_{i in C_r(T)} Delta_m(T, i | P_r)`. Update is `P_{r+1}(T) = P_r(T) union {i_r*}` and `C_{r+1}(T) = C_r(T) \ {i_r*}` until `C_r` is empty. Output prune order for `(m, T)` is `[i_0*, i_1*, ...]`. No information is shared across different targets `T`.

**Baseline losses.** For each target index `t` in `0 .. num_steps-1`, the clean cross-entropy on that step is `calculate_step_loss(clean_logits, clean_ids[0], step_start, step_end)`, which uses logits from `start` through `end-2` to predict labels from `start+1` through `end-1` so the first token of a step (boundary) does not contribute loss. The script also records `prediction_token_count_per_step` as `max(0, e - s - 1)` for downstream joint-metric tooling.

**Invariant structure.** For each target `T`, each intervention method maintains its own `pruned` set and `candidates` set. Candidates are always `{0,..,T-1}` initially: the target step itself is never ablated as a “source.” Each round evaluates every remaining candidate, then greedily commits the candidate with the **lowest mean loss delta** on step `T` (mean over corruption files where applicable). The chosen index is removed from candidates and added to `pruned`; trials for the next round apply **all** pruned sources simultaneously. Nothing carries across different targets: target `T+1` starts fresh.

**Method: `attn_supp`.** Implemented in `run_attn_supp_for_target`. For candidate source step `i` with current `pruned` set, the code builds the list of token spans for all pruned steps plus `i`, takes the prefix up to the start token of step `i`, slices the full KV cache to that prefix, and runs the model on the suffix `clean_ids[:, prefix_len:]` with absolute `position_ids` continuing from `prefix_len`. Inside `CumulativeAttnSuppressionContext` from `run_backward_ablation.py`, every layer’s attention forward is monkey-patched so that for each suppression span `(src_start, src_end)`, any query position whose absolute index is at least `src_end` cannot attend to keys in `[src_start, src_end)`. That approximates removing those keys from later causal influence without re-running the prefix. Loss is `calculate_step_loss` on the target span expressed in **suffix-local** indices.

**Method: `resample` and `perturb_text`.** Both use `run_resample_for_target` with different corpora of per-step strings. For each candidate `i` and each corruption variant, the code clones the list of clean step strings, sets step `i` to the variant’s string for `i`, and for every `j` in `pruned` also overwrites step `j` with that variant’s strings, then rebuilds the full document text with `_rebuild_text(working, gaps)` where `gaps` preserve inter-step material from the clean CoT. The rebuilt string is tokenized, the think block is re-parsed, and `new_ranges` must contain exactly `num_steps` steps with the same inner-think alignment checks. Loss is computed on `new_ranges[target_t]` against the **re-tokenized** sequence logits (so the model sees a coherent alternate text, not a KV splice).

**Method: `perturb`.** Implemented in `run_kv_perturb_for_target`. For each perturbation file and candidate `i`, the substituted step index set is `{i} ∪ pruned`. The perturbed token spans for those indices are collected in sorted order. `query_mix_start_for_kv_substitution` returns either the end index of step `i` if there are no other substituted steps (post-source mixing only) or the minimum span start among all substituted steps if multiple steps are spliced (so no query reads a pruned step with clean K/V). `PerturbedKVPostSourceContext` patches attention: batch is `[clean_ids, pert_ids]`; for the clean row, keys and values are cloned from the clean branch and overwritten on each `source_spans` interval with the perturbed branch’s K/V; queries before `query_mix_start` use a fully clean attention matrix; from `query_mix_start` onward the tail uses mixed K/V and the causal mask appropriate to full sequence length. Loss is always measured on the **clean** token indices and labels for target step `T` on the mixed forward’s logits at batch index zero. If a `JointBaselineTable` was loaded from `--joint-baseline-json`, each candidate also stores normalized joint metrics via `sum_logprob_at_step` and `joint_baseline.joint_norm`, i.e. `(p - p_base)/(p_clean - p_base)` in probability space derived from summed log-probabilities (see `causal_cot/src/joint_token_likelihood.py`).

**Output.** The JSON schema includes `methods` with keys `attn_supp`, `resample`, `perturb`, `perturb_text`, each holding `by_target` dictionaries keyed by stringified step indices, containing `prune_order`, per-round records with `candidate_mean_delta`, `candidate_ppl_ratio`, optional `candidate_per_corruption_deltas`, and optional normalized joint fields for perturb rounds when baselines match `num_steps`.

## SSEP (Single Step Edge Pruning)

SSEP lives in `causal_cot/src/pruning_ssep.py` with entrypoints from `causal_cot/train_ssep.py`. It learns **one vector of L0 masks per target reasoning step** `k` (in the training code’s one-based indexing: `k` in `2..N` for `run_single_step`, or `k = N` only in `run_pruning`). Masks have length `k-1`: one scalar `z[si-1]` for each source reasoning step `si` in `1..k-1` controlling whether keys and values in step `si` come from the clean or perturbed run when queried from later positions.

**Formal specification.** Fix a target step `k` (one-based, prompt is step `0`). Train parameters are `alpha^{(k)} in R^{k-1}`. At each optimizer step sample `z^{(k)} ~ HC(alpha^{(k)})`. For any attention query token position `q` and key position `t`, let `step(t)` be the step id of key token `t` and `end(step(t))` its exclusive end index. Mixing is active iff `1 <= step(t) < k` and `q >= end(step(t))`; in that region use score interpolation `S_f = S_p + z_{step(t)} * (S_c - S_p)` (index-shifted by one in code), outside that region use clean scores (`z=1`). Clean-row outputs use mixed scores/values; perturbed row remains standard perturbed attention. Let `CE_k(z)` be the clean-row CE on target-step prediction tokens and `CE_k^clean` the no-hook baseline. Faithfulness loss is `L_f = CE_k(z) - CE_k^clean`. Edge sparsity for step `k` is `S_k = 1 - mean(z^{(k)})`, target `tau_k` warms up linearly to configured `target_sparsity`, and regularizer is `L_reg = lambda_1*(S_k - tau_k) + lambda_2*(S_k - tau_k)^2`. Per-iteration objective averaged across perturbation samples is `L = L_f + L_reg`. Final discrete edges are `{(i, k) : deterministic_z_i > 0, 1 <= i < k}`.

**Parameter container.** `_StepParams` holds `log_alpha` of shape `(k-1,)` and `sparsity_lambda_1/2` initialized from the outer module’s current regulators so each single-step optimization can reuse the same dual-variable scale.

**Hooked attention.** When batch size is not two, attention is standard. When batch size is two (row zero clean, row one perturbed), the module uses `custom_attention_forward`. Rotary embeddings and KV repetition follow the Qwen-style path. `Z_step = sample_z_from_log_alpha(step_params.log_alpha)` is stored as `_cached_Z`. For each key position, `token2step` assigns a reasoning step id via `assign_token2step_tensor` on `step_ranges` (prompt is step zero; reasoning steps cover the think-inner contiguously). `z_per_key` assigns `Z_step[si-1]` to all positions whose step id equals `si` for `si < target_k`; other keys use weight one (no mixing). `key_step_end` stores the exclusive end index of each key’s step. For each query chunk, a boolean `query_in_window` requires `q >= key_step_end[key]` so mixing only affects queries **at or after the end of the source step**, matching the docstring’s “every query token at positions q >= end(step i)”. `apply_mix` further requires the key to lie in a learnable source step (`1 <= token2step < target_k`). The effective mixing weight per (query, key) is one outside that region. Logits scores use `S_f = S_p + Z * (S_c - S_p)` for the clean-query row, then softmax, then value reconstruction `A_Z V_clean + (A_f - A_Z) V_pert` which is algebraically equivalent to weighting values by the post-softmax mixture implied by mixed logits. The perturbed batch row uses standard SDPA on the fully perturbed branch.

**Loss and regularization.** For each optimizer step and each perturbed sequence in the list, the code concatenates `[clean, pert]`, runs the model with embeddings’ gradients enabled and gradient checkpointing, takes logits on the clean row only, slices to the target step’s prediction window, and computes mean cross-entropy versus clean labels. The faithfulness term is `delta_loss = m_loss - clean_loss` where `clean_loss` was precomputed for that `k`. Sparsity is `1 - mean(z)`. During the first `warmup_steps` optimizer iterations, the target sparsity ramps linearly from zero to `target_sparsity`; afterward it stays at `target_sparsity`. The regularizer matches JSEP’s edge form: `lambda_1 * (current_sparsity - current_target) + lambda_2 * square`. Total loss is `delta_loss + reg_loss`, scaled by `1/num_perts`, summed over perturbations before `optimizer.step`. AdamW groups come from `get_optimizers` on `_StepParams` only.

**Checkpoints and output.** At sparsity interval targets `(i/(N-1))` for `i` in `1..N-2`, when instantaneous edge sparsity is within half a bin width and faithfulness improves the stored best for that bin, the code saves `log_alpha`, sampled `z`, lambdas, step index, sparsity, and faithfulness loss to `log_alpha_step_{k}_interval_{ckpt_i}.pt` under `results/checkpoints_ssep` by default. After training, `deterministic_z_from_log_alpha` on the detached `log_alpha` yields hard edges `(i, k)` for each source `i` with `final_z[i-1] > 0`.

## JSEP (Joint Step Edge Pruning)

JSEP is implemented in `causal_cot/src/hooks_jsep.py` and launched from `causal_cot/train_jsep.py`. It maintains a full **upper-triangular** learnable matrix `log_alpha` with shape `(N+1, N+1)` where index zero is the prompt and indices `1..N` are reasoning steps. Entry `Z[r,c]` for `r < c` represents how much queries in step `c` attend **as if** keys and values came from the clean predecessor step `r` versus the perturbed graph; the diagonal and entire prompt row and column are forced to one after sampling, so the prompt is always clean-connected and self-loops are fixed.

**Formal specification.** Train parameters are edge logits `Alpha in R^{(N+1)x(N+1)}` (used on strict upper triangle of reasoning indices) and optional node logits `beta in R^{N-1}`. Each step samples `Z_raw ~ HC(Alpha)` and enforces constraints: prompt row/column and diagonal set to one; invalid lower-triangular entries ignored. If node sparsity is enabled, sample node gates `g ~ HC(beta)`, construct `node_gate = [1, g_1, ..., g_{N-1}, 1]`, and row-scale edges so outgoing edges from gated-off nodes are suppressed. For each query/key token pair, define step ids `(u, v)` and use mixed clean-row attention score interpolation `S_f = S_p + Z[v, u] * (S_c - S_p)` (implemented via transpose lookup `Z.T[q_step, k_step]`); perturbed row uses standard perturbed attention. Let per-step CE deltas be `delta_j = CE_j(mixed) - CE_j(clean_baseline)` for reasoning steps `j=1..N`. Usage weights `U_j` are computed recursively from `Z` (`calculate_usage_probabilities`) and represent downstream contribution weights. Faithfulness term is either `sum_j U_j * delta_j` (`weighted_sum`) or `sum_j ReLU(U_j * delta_j)^2` (`squared_sum`). Edge sparsity is mean `1-Z` over strict upper triangle of reasoning block; optional node sparsity is `1-mean(g)`. With warmup targets, total loss per iteration is faithfulness plus edge regularizer plus optional node regularizer, each in linear-plus-quadratic Lagrangian form.

**Node gating (optional).** If `use_node_sparsity` is true, an additional vector `node_log_alpha` of length `N-1` samples masks for reasoning steps `1..N-1` (the final step has no outgoing edges in the discrete graph story). After sampling the upper triangle of `Z_raw`, the implementation multiplies each row `r` in `1..N` by `node_gate[r]` where `node_gate = [1, z_1, ..., z_{N-1}, 1]`, zeroing outgoing edges from pruned nodes. If node sparsity is disabled, cached node values are treated as all ones and node regularizers are omitted; checkpoint payloads still store dummy node tensors for compatibility.

**Usage probabilities.** `calculate_usage_probabilities` implements the recursive formula in the module docstring: working backward from step `N-1` down to `1`, it maintains log-terms `v_j` such that each step’s usage `U_j` derives from products over later connections weighted by `1 - Z[j,k](1-exp(v_k))`, clamped for numerical stability, ending with `U = 1 - exp(v_stack)`. These `U` weights scale how much each reasoning step’s CE increase matters in the global faithfulness objective.

**Hooked attention (clean-query mixed K/V).** For `bsz == 2`, the clean query row reuses the same `S_f = S_p + Z_c * (S_c - S_p)` construction as SSEP, except `Z_c` is built per chunk from `Z.T[q_step_id, k_step_id]` for each query and key token’s step ids (transpose matches the code’s comment that `Z.T[q_step, k_step]` is the mix weight for query step attending to key step). Causal masking uses `torch.tril` with `diagonal=i` for chunk start `i` to respect positions. The perturbed row uses unmodified SDPA. Memory is managed in chunks of 128 query positions and explicit `del` of intermediates.

**Training objective.** Clean baseline CE per step `1..N` is precomputed once without hooks. Each step samples a fresh `Z`, caches it, runs the batched forward with gradient checkpointing and trainable embeddings, and computes per-step CE on the clean targets against the **mixed** logits on the clean sequence row. Deltas are `step_loss - clean_step_losses[k]`. If `faith_loss_fn == "weighted_sum"`, the faithfulness loss is `sum_k U[k-1] * delta_k`. If `"squared_sum"`, it is `sum_k ReLU(delta_k * U[k-1])^2`. Edge sparsity is the mean of `1 - Z` over valid upper-triangular entries among reasoning indices only (`Z[1:N+1,1:N+1]` strict upper triangle). Edge and node targets warm up linearly for the first `warmup_steps` iterations to the configured `target_sparsity` and `target_node_sparsity`. Regularization uses the same linear-plus-quadratic form with learnable `sparsity_lambda_1/2` and optional node lambdas. Total loss per perturbation is `(faithfulness + edge_reg + node_reg) / num_perts` accumulated over the inner loop before one optimizer step. Optimizer groups split `log_alpha`, `sparsity_lambda` for edges, and optionally `node_log_alpha` and `sparsity_lambda_nodes`, with scheduler warmup steps configurable separately.

**Interval checkpoints.** When optimizing with node sparsity, checkpoints trigger on proximity of **model node sparsity** to fractions `i/(N-1)`; in edge-only mode they trigger on **edge sparsity** instead. The code keeps the lowest faithfulness loss seen per interval and saves tensors including `log_alpha`, `sampled_Z`, lambdas, sparsities, and flags.

**Evaluation helpers.** `causal_cot/src/checkpoint_eval.py` defines `build_deterministic_Z` which binarizes saved soft edge and node masks by threshold search to preserve mean sparsity, rebuilds a `(N+1)x(N+1)` `Z`, applies symmetric node gating (note this differs slightly from training’s row-only node multiply), forces prompt and diagonal, and supplies `eval_at_Z` which runs the pruner with a fixed `Z` and reports ancestor-weighted delta statistics using graph reachability on the binarized matrix.

## GSNP (Greedy Step Node Pruning)

GSNP is implemented in `causal_cot/run_gsnp.py` as another **frozen-model** greedy loop, but it prunes **entire reasoning steps as nodes** (indices `0 .. N-2`; the final step `N-1` is never a prune candidate) using **only** the K/V perturbation splice mechanism, not attention suppression or text rebuilds. Each round considers every step `i` still in the candidate set. For each perturbation file, it forms a batch `[clean_ids, pert_ids]`, sets `subst_steps = {i} ∪ pruned_set`, builds perturbed spans for those steps, computes `mix_start = query_mix_start_for_kv_substitution(i, subst_steps, clean_token_ranges)`, and runs the model under `PerturbedKVPostSourceContext`. For every **later** step `j > i` that is not yet pruned, it records the mean CE loss on the clean span minus the precomputed clean baseline for `j`, accumulating sums over perturbation files.

**Formal specification.** Let prune-eligible node set be `V = {0, ..., N-2}` and current kept future set for candidate `i` be `J_i = {j : j > i and j not in P}` where `P` is the already-pruned node set. For each round and each `i in V \ P`, compute per-future-step averaged deltas `d_i(j) = mean_c[ CE_mixed^{(c)}(j; P union {i}) - CE_clean(j) ]` and optionally averaged joint-normalized scores `q_i(j)` when baseline tables are provided. Under `relative_ppl`, define bottleneck `j_i* = argmax_{j in J_i} d_i(j)` and score `s_i = d_i(j_i*)`; choose prune `i* = argmin_i s_i` (minimax CE delta). Under `joint_prob_ratio` with baseline, define bottleneck `j_i* = argmin_{j in J_i} q_i(j)` and choose `i* = argmax_i q_i(j_i*)` with tie-breakers (lower CE delta, then lower index), i.e. maximin normalized joint. Update `P <- P union {i*}` and repeat until all eligible nodes are pruned or stop condition is reached.

**Ranking metrics.** For each candidate `i`, the code reduces the dictionary of average deltas over later `j` in one of two ways chosen by `--prune-metric`. Under `relative_ppl`, it takes `j_worst = argmax_j avg_diffs[j]` and sets `step_scores[i] = avg_diffs[j_worst]`, i.e. the **worst** average CE increase among surviving future steps (the bottleneck under mean CE). The chosen prune is `argmin_i step_scores[i]`, a **minimax** rule: remove the node whose worst damage to any future step is smallest. The logged `ppl_ratio` is `exp(score)` at that primary worst step. Under `joint_prob_ratio` with a loaded `JointBaselineTable`, for each `i` it converts averaged summed log-probs per later `j` into `joints[j] = joint_baseline.joint_norm(avg_logp[j], j)`, identifies the **bottleneck** later step with minimum normalized joint, sets `step_scores[i]` to the mean CE delta at that same bottleneck step (for tie diagnostics), stores `joint_for_pick[i]` as that bottleneck’s normalized joint value, and selects `i` that **maximizes** `joint_for_pick[i]` with tie-breaks toward lower delta and lower index—a **maximin** on the normalized joint. Without a baseline file but still using the joint metric name, it falls back to legacy `exp(-K_j * avg_diffs[j])` at each `j` with `K_j` the step’s prediction token count, takes the minimum over `j` as bottleneck, and ranks by that surrogate.

**Curve logging.** The JSON and CSV writers store each round’s `pruned_step`, `max_affected_step` (the index `j_star` used for the primary score), `score`, `ppl_ratio`, `joint_prob_ratio`, cross-metric fields `worst_rel_ppl_ratio` and `bottleneck_joint_prob_ratio`, and the full `all_scores` map. The embedded PNG plots sparsity `xs` as the fraction of non-final steps removed versus `ys` defined so the curve always reflects **max relative PPL over later steps** for the chosen prune each round: under `relative_ppl` that equals the primary `ppl_ratio`; under `joint_prob_ratio` it uses the auxiliary `worst_rel_ppl_ratio` field so the vertical axis stays a PPL-style minimax tail even when selection used joint maximin.

**Defaults and validation.** The script defaults to five perturbation files (or fewer with a warning), asserts strict token alignment between clean and each perturb file identical to GSEP’s perturb path, optionally loads `joint_step_logprobs.json` for normalized joints, and writes under `results/gsnp_ppl_output` or `results/gsnp_joint_prob_output` depending on metric.

## GSNP_GSEP (Greedy Step Node Pruning + Greedy Step Edge Pruning)

`GSNP_GSEP` is implemented in `causal_cot/run_gsnp_gsep.py` as a two-stage frozen-model pipeline that combines node-level and edge-level greedy pruning on the same reasoning trace. Stage one runs GSNP to greedily prune whole source reasoning steps (nodes). Stage two runs GSEP-style per-target edge pruning on the reduced source set induced by stage one, so edge selection is conditioned on which nodes survived.

**Formal specification.** Stage 1 computes an ordered node-prune sequence `pi_node = [v_0, v_1, ...]` using GSNP rules. For each node sparsity level `rho`, define surviving node set `S(rho)` by removing the first `floor(rho * (N-1))` entries of `pi_node` from `{0, ..., N-2}`. Stage 2 then runs GSEP independently for each target `T` but restricts source candidates to `C_0(T, rho) = {i in S(rho) : i < T}`; greedy edge/source selection within each target is otherwise identical to standard GSEP (same intervention operators and same argmin mean-delta rule). The pipeline output is therefore a family of per-target prune orders parameterized by node sparsity level, plus the GSNP trajectory used to generate those candidate sets.

**Shared mechanics.** The pipeline reuses the same perturbation files, step parsing, token-range alignment checks, and K/V substitution primitives used by `run_gsnp.py` and `run_gsep.py`, so all interventions operate on the same token spans and corruption variants.

**Outputs.** The script logs the GSNP trajectory and subsequent GSEP-by-target results together, aligned on a shared sparsity/progress axis so downstream plotting can compare node-removal and edge-removal effects in one run.

---

Together, Edge-Pruning learns a subgraph of internal reader-writer connections inside a Llama-compatible circuit with KL distillation from a dense teacher and L0 gates; GSEP scores discrete backward ablations per target step with four different intervention types and no cross-target state; SSEP fits a small set of L0 parameters per target step with a single-step CE surrogate and per-source K/V mixing on a fixed window of queries; JSEP fits a joint step-to-step mixing matrix with optional node gates and a usage-weighted multi-step faithfulness loss; GSNP greedily removes whole reasoning steps under a global minimax CE or maximin normalized-joint criterion using the same K/V splice primitive as GSEP’s perturb method; GSNP_GSEP chains node pruning then edge pruning in one frozen-model pipeline.
